Selected work in LLM agents, time-series forecasting, and deep learning.

  • VAI: AI-Driven Functional Verification for Digital Designs

    Graduation Project · LLM Agents · Hardware Verification

    An autonomous LLM agent that tests chip designs by itself: it reads the design, writes test inputs, runs them in a live simulator, and keeps going until every required behaviour has been exercised.

    • Reached full coverage on 4 of 5 open-source designs and closed 84% of the testing gaps left by the traditional method (average coverage 89% → 98%).
    • Reached full coverage in 7 minutes on average, compared with 60-minute traditional runs that still fell short, at an average LLM cost of ~$0.30 per design.
    • Wrote a layered system prompt defining the agent's role, constraints, tool-usage rules, code-generation conventions, and error-recovery behaviour.
    • Designed an MCP-style tool layer with structured outputs, separating the model's generated code from tool-invocation schemas via runtime state injection.
    • Implemented a stratified context-management layer with a tiered memory hierarchy and per-tier token budgets, plugged into the graph as a pre-model hook and persisted across process restarts via checkpointing.
    • Engineered agent-driven memory dynamics: the model summarises its own over-budget context slices, and chains of trial-and-error collapse into single durable lessons via the agent's narrative tags.
    • Built a persistent cross-run memory: many-to-many strategy storage with deduplication, plus a project-scoped relational knowledge base with module-aware signal disambiguation for retrieving past solutions.
    • Designed the VAI score, a novel composite metric for benchmarking AI-driven verification.

    Python · LangGraph · LangChain · MCP

  • Real-Time ECG Waveform Forecasting

    Research Internship, Nile University · Time-Series · Foundation Models

    A real-time system that forecasts the next second of a patient's ECG beat by beat, plus a new way to measure whether those forecasts are actually right.

    • Split the signal into beat timing, beat type, beat shape, and a slow low-frequency component, forecast by a zero-shot Chronos model, a beat-type classifier, and fine-tuned Chronos-Bolt models.
    • Achieved NMAE of 0.018 and MSE of 0.10 on patients never seen in training.
    • Designed a new per-beat metric scoring timing, height, and shape separately, since standard error metrics blend these errors and can reward flat, smeared forecasts. The typical forecast placed beats within 15 ms (about 2% of a heartbeat) at 76% of their true height, with 27% shape error.
    • Outperformed the FADE paper (2025) on normal rhythm under equal conditions, using its open-source code and training split: 14% lower NMAE, 7% lower MAE, and beats at 81% vs. 72% of true height.
    • Explored reservoir computing, next-generation reservoir computing (NG-RC), and Transformers along the way.

    Python · PyTorch · Chronos · Transformers · Fine-tuning

  • Motor Imagery Classification↗ GitHub

    Deep Learning · EEG / BCI · PyTorch

    End-to-end EEG pipeline for classifying motor-imagery signals from a Muse-S headset, from raw recordings to trained CNN / Bi-LSTM models.

    • Segmented continuous Muse-S EEG into epoch-labelled DataFrames with subject and session metadata.
    • Automated MNE-Python preprocessing: band-pass and notch filtering, ICA artifact removal, CAR, and z-score normalisation.
    • Offline augmentation (Gaussian noise, temporal shifts, window jitter), packaged into efficient PyTorch Dataset / DataLoader pipelines.
    • Implemented and fine-tuned EEGNet-8-2 CNN and Bi-LSTM models in PyTorch / TensorFlow with reproducible training and checkpointing.

    Python · PyTorch · TensorFlow · MNE
