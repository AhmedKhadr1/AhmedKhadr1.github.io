Projects

Selected work in deep learning, signal processing, and classical ML.

  • AI-Driven Functional Verification for Digital Designs

    Graduation Project · LLM Agents · Hardware Verification

    An autonomous LLM agent that closes functional coverage on digital designs by iteratively planning, generating, validating, and reacting over a tool-calling protocol with a custom memory stack and a novel quantitative benchmark.

    • Designed an autonomous ReAct LLM agent that closes functional coverage on digital designs through iterative plan–generate–validate–react loops over a tool-calling protocol.
    • Authored a layered system prompt covering role, invariants, tool-tier discipline, code-generation conventions, and error-recovery semantics establishing the primary behavioural contract for the agent.
    • Designed an MCP-style tool layer with a structured-output contract that decouples the model's code-emission surface from invocation schemas via runtime state-injection wrappers.
    • Implemented a stratified context-management layer with a tiered memory hierarchy and per-tier token budgets, plugged into the graph as a pre-model hook and persisted across process restarts via checkpointing.
    • Engineered agent-driven memory dynamics the model summarises its own over-budget context slices, and chain trial-and-error sequences collapse into single durable artefacts via the agent's narrative tags.
    • Architected a persistent agent-memory layer combining many-to-many strategy storage with deduplication, alongside a project-scoped relational knowledge store with module-aware signal disambiguation for cross-run retrieval.
    • Developed the VAI score, a novel composite quantitative metric for benchmarking AI-driven verification designs.

    Python · LangGraph · LangChain · ReAct · MCP-style tools

  • Motor Imagery Classification↗ GitHub

    Deep Learning · EEG / BCI · PyTorch

    End-to-end EEG pipeline for classifying motor-imagery signals from a Muse-S headset from raw recordings to trained CNN / Bi-LSTM models.

    • Segmented continuous Muse-S EEG into epoch-labelled DataFrames with subject and session metadata.
    • Automated MNE-Python pipeline: band-pass + notch filters, ICA artefact removal, CAR, z-score normalisation.
    • Offline augmentation (Gaussian noise, temporal shifts, window jitter); packaged into efficient PyTorch Dataset / DataLoader.
    • Fine-tuned EEGNet-8-2 CNN and Bi-LSTM models in PyTorch / TensorFlow with reproducible training and checkpointing.

    Python · PyTorch · TensorFlow · MNE · Pandas · NumPy

  • San Francisco Crime Classification↗ GitHub

    Classical ML · Geospatial · LightGBM

    Multi-class classification on the SF crime dataset from feature engineering through to spatial visualisation and model benchmarking.

    • Parsed temporal features, removed spatial outliers and duplicates, one-hot-encoded categoricals, standard-scaled numerics.
    • Trained tuned Random Forest, LightGBM, and Logistic Regression classifiers.
    • Benchmarked performance with multi-class ROC curves and produced spatial crime visualisations.

    Python · Scikit-learn · LightGBM · Pandas · Matplotlib
